# CFD_Datasets_for_ML
Computational fluid dynamics datasets for ML based surrogate modeling!

## CFD Datasets

### 1. JHU Turbulent
https://turbulence.idies.jhu.edu/home

Recommend using with sciserver, and need the tokens from JHU team (send the email!)

### 2. Snapshot Dataset
https://arxiv.org/pdf/2206.11801

Can easy-download snapshot dataset

### 3. OpenFOAM Tutorials
https://www.openfoam.com/documentation/tutorial-guide

### 4. The Well: 15TB Multi-Physics Dataset
https://github.com/PolymathicAI/the_well

### 5. JAX_CFD Tutorials
https://github.com/google/jax-cfd
